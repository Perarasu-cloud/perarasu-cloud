## ⚡ Project in 30 Seconds

A **Double Wishbone Suspension System** designed and modelled using CAD, then evaluated through **Finite Element Analysis (FEA)** to study stress, deformation, load distribution and Factor of Safety.

## 🔬 FEA Analysis

The design was evaluated using **Finite Element Analysis** to examine:

| Analysis | What it tells us |
|---|---|
| **Stress** | How stress is distributed through the design |
| **Deformation** | How the structure responds to loading |
| **Load Distribution** | How applied loads are distributed |
| **Factor of Safety** | Structural design validation |
